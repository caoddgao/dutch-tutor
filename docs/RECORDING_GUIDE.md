# 录音说明

这份说明给帮忙录荷兰语的人看。录音在 Dutch Tutor 里完成，不需要另外安装录音软件。

1. 打开 **设置 → 录音模式**。先选一课，点“导出录音稿”，把 HTML 文件保存在电脑上。用浏览器打开，可以打印。
2. 录之前把整课稿子读一遍。觉得某句说法别扭、需要改写时，在稿子上做记号，并在程序里勾选该句的“这句不自然”。**不用先录音也能标记。** 原书句子也可以只标记，暂时跳过。
3. 从第一课开始，按录音稿的编号依次录。每句先听当前音源，再点“录这一句”；读完点“停止录音”，用“回放”检查。满意才点“满意，保存”，不满意就重新录。词也要逐个录。
4. 可以勾选“只看未录的”继续上次的进度。保存后，课程中的该句或词会直接改用真人录音；录音文件保存在本机的应用数据文件夹。
5. 录完一批后点“导出录音”，选择一个空文件夹。把整个文件夹交回去，里面有录音和“不自然”标记。接收方在同一页点“导入录音”，选择这个文件夹即可。**请把整个文件夹一起传送，不要只发音频文件。**

录音稿只在你的电脑上生成；不要把含原书课文的录音稿提交到代码仓库。
