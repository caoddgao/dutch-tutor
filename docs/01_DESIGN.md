## 0. 定位与范围

- **是什么**：一个在 Windows 11 上运行的**单机、单用户**荷兰语学习桌面程序。独立窗口，不依赖浏览器，不需要后台服务。
- **给谁用**：老旦本人。中文母语，荷兰语零基础（字母还读不全），目标是为荷兰境内的融入考试（inburgeringsexamen）打 A1 基础。
- **这次只做 A1**。A2、B1、B2 在界面和数据结构上预留位置，显示为"即将推出"，不施工。
- **核心教材**：官方免费资料 *Naar Nederland*（Basisexamen Inburgering Buitenland 的自学包）。KNS（社会知识）的电影和照片题不用，只把其中的常识揉进课文话题。
- **平台**：先做 Windows 11 64 位。技术选型保证以后能出安卓版，不重写。
- **联网**：学习全程离线可用。只有可选的 Azure 发音评分需要联网。

## 1. 设计原则（全部来自用户的明确要求）

1. **零基础友好**：句子短，A1 每句原则上 ≤ 5 秒；先听、跟读，再练。
2. **荷、中、英三语**：每个句子、每个词都有中文和英文释义。英文可随时开关。
3. **像词典一样的词条**：词性、名词的 de/het 冠词和复数、动词的常用形式。
4. **不考打字、不默写**。所有作答都是点选、排词块或开口说。
5. **课程不锁**：所有课随时可进，可以跳着学、反复学。
6. **复习不进课堂**：课程只教新内容；复习有单独入口，可以按课复习，也可以做"今日复习"。
7. **发音和单词一起学**：例如 oe 和 boek、goed 一起学，ui 和 huis、thuis 一起学。
8. **语法用"小贴士"简短说明**：发音入门（P 课）只学语块；从正课第一课（第 21 课）起出现小贴士，不出专门的语法考题。
9. **内容写死在程序数据里**，运行时不调用大模型。
10. **真人语音优先**：Naar Nederland 原版录音 > 你儿子的录音 > Azure 合成音。合成音只是占位，可以被逐句替换。

## 2. 课程结构

### 2.1 两条线 + 测验

| 线 | 编号 | 内容 | 来源 |
|---|---|---|---|
| **发音入门** | P01–P10（约） | 每课 2–3 组音：音 + 关键词 + 几句实用短句；练"听音选拼写""看拼写选读音" | NN 第 1–13、20 课的音组和关键词；短句由我们写 |
| **正课** | 用 NN 课号：第 21 课 … 第 65 课 | 每课一段原版对话或短文（约 20 句）+ 词卡 + 小贴士 + 练习 | NN 第 21–65 课 |
| **阶段测验** | 测验 1 / 2 / 3 | 分别在第 35、45、55 课之后 | NN 的 Tussentoets 1–3 |
| **结业模拟考** | 1 套 | 按真实考试的口语和阅读题型 | 我们自己出题 |

- **正课直接沿用 NN 的课号**（"第 21 课 · Wat is uw naam?"），方便和纸质书对照。
- **生词过多的课一拆为二**（例如"第 24 课 a / b"）。拆分规则：新词 > 45 个，或课文句子（不含课题和词表朗读）> 36 句（2026-10-11 由 24 改为 36）。拆分点不拆开一问一答。具体拆哪几课，等资料包里的统计出来再定，写进附录"逐课清单"。
- **NN 第 1–20 课里的 14–19 课**（情景小文）：并入发音入门 P05–P10，每课末尾一篇"认读小文"（NN14→P05 … NN19→P10）：听原版 → 逐句跟读，不另出题（2026-10-11 定）。
- 预计总数：发音入门约 10 课 + 正课约 50–55 课 + 3 次测验 + 1 套模拟考。每课 20–30 分钟。

### 2.2 课的状态（不锁课）

- 每课有三种状态：**未学 / 学过 / 掌握**。
  - "学过"：完整走完过一遍。
  - "掌握"：本课 ≥ 80% 的句子和词在复习中达到"熟练"（间隔 ≥ 7 天）。
- 课程地图上高亮一个"推荐下一课"（第一个"未学"的课），只是建议，不强制。

### 2.3 小贴士（语法点）

- 每条小贴士讲一个点，中文说明 2–4 句 + 2–3 个例句（荷 / 中 / 英）+ 可选的小表格（比如变位表）。
- 出现在它第一次明显用到的那一课；之后的课里同一个点可以链接回去，不重复讲。
- 不出专门的语法练习题。语法的掌握靠句子练习和口语练习自然带出。
- 初步清单（课次在资料包统计后排定）：

| 编号 | 语法点 |
|---|---|
| G01 | 人称代词（ik, jij/je, u, hij, zij/ze, wij/we, jullie, zij/ze） |
| G02 | zijn（是）和 hebben（有）的现在时 |
| G03 | 规则动词现在时：ik woon / jij woont / hij woont / wij wonen |
| G04 | 疑问句：动词提前；疑问词 wat / waar / wie / hoe / wanneer |
| G05 | 问句里 jij 后置时动词去 t：Woon jij…? |
| G06 | 冠词 de / het / een；指示词 deze / dit / die / dat |
| G07 | 复数 -en / -s |
| G08 | 否定：niet 和 geen |
| G09 | 动词第二位（V2）：Vandaag werk ik. |
| G10 | 物主代词 mijn / jouw / uw / zijn / haar / ons / onze |
| G11 | 情态动词 + 原形：Ik wil … / Ik kan … / Ik moet … |
| G12 | 可分动词：opbellen → Ik bel je op. |
| G13 | 形容词加 -e：een mooie fiets / het grote huis |
| G14 | 现在完成时：Ik heb … gedaan / Ik ben … gegaan（应对考试"你昨天做了什么"） |
| G15 | er 的常见用法：Er is … / Er zijn … |
| G16 | 时间和数字的说法（钟点、星期、日期） |

## 3. 一课的流程

正课的标准流程如下。发音入门课用简化版：音 → 关键词 → 短句 → 听辨练习（P05–P10 再加“认读小文”：听原版 → 逐句跟读，见 §2.1）。

| 步 | 名称 | 内容 | 预计 |
|---|---|---|---|
| ① | **听原版对话** | 完整播放 NN 原版录音一遍到两遍；文字默认隐藏，可展开；可显示中文 | 2–3 分钟 |
| ② | **逐句学** | 一屏一句：荷兰语大字、中文、英文（可关）；播放 / 0.75 倍慢放 / 录音跟读并和原声对比；点任意词看词条 | 8–12 分钟 |
| ③ | **词卡** | 本课新词，一屏一张：词条全貌 + 本课出现它的句子 + 读音 | 3–5 分钟 |
| ④ | **小贴士** | 0–2 条，从第 21 课开始出现 | 1–2 分钟 |
| ⑤ | **练习** | 课本练习全部收录 + 自动出题 ≤ 9 道（一课约 15–25 小题），含考试同款题型 | 8–12 分钟 |
| ⑥ | **完成** | 本课的句子和词进入复习队列；显示本课小结 | — |

- 每一步都可以跳过或返回；退出时记住位置，下次从这里继续。
- 一课约 15–20 句（NN 原版句子为主），可以加 0–5 句我们补充的实用短句。像 hallo、hoi 这类词不单独占位置，而是放在句子里学。

### 3.1 练习题型

| 代码 | 题型 | 作答方式 | 对应考试 |
|---|---|---|---|
| E1 | 听句选意思 | 播放荷兰语 → 从 4 个中文（+英文）选项里选 | 口语-理解 |
| E2 | 看句选意思 | 显示荷兰语 → 选意思 | 阅读 |
| E3 | 听词选拼写 | 播放一个词 → 从 4 个写法里选 | **阅读-技术性阅读** |
| E4 | 看拼写选读音 | 显示一个词 → 从 4 段读音里选 | **阅读-技术性阅读** |
| E5 | 补全句子（口头） | 听一句情景句 + 下一句的开头 → 开口补完 → 显示参考答案 → 自评或 Azure 评分 | **口语-Zinnen afmaken** |
| E6 | 问答（口头） | 听一个日常问题 → 开口回答 → 显示 2–3 个参考答案 → 自评或评分 | **口语-Vraag en antwoord** |
| E7 | 词块排序 | 点词块拼成句子 | — |
| E8 | NN 原书练习 | 判断对错 / 二选一 / 连线配对 / 选词填空，全部点选 | — |
| E9 | 短文阅读 | 一篇短文 + 2 道选择题（从正课中段开始） | **阅读-功能性阅读** |

- NN 原书里依赖图片的练习不做（资料包里标记跳过）。
- E5 和 E6 的题目由我们按课文话题来写。

## 4. 复习系统

### 4.1 复习什么

- 复习对象是**句子**和**词**。小贴士不进复习。
- 一课标记"学过"后，这一课的句子和新词进入复习队列。

### 4.2 三种复习方式（都不打字）

| 代码 | 方式 | 说明 |
|---|---|---|
| R1 | 看荷兰语 → 选意思 | 4 个选项（中文为主，英文开着就同时显示） |
| R2 | 只听不看 → 选意思 | 只播放录音，不显示文字 |
| R3 | 看中文 / 英文 → 开口说荷兰语 | 说完播放原声对比，自评"会 / 模糊 / 不会"；配了 Azure 就同时显示评分 |

- 系统自动轮换三种方式。设置里可以关掉某一种。
- 选择题的干扰项从同课或相邻课里抽取，同词性、长度相近，避免一眼就能排除。

### 4.3 间隔安排

- 采用简单阶梯：1 → 3 → 7 → 14 → 30 → 60 天，之后每次 ×1.7。
- 答错或"不会"：当天再出现一次，间隔回到 1 天。"模糊"：间隔不升级。
- 算法放在单独的模块里，以后可以换成 FSRS。

### 4.4 入口

- **今日复习**：所有到期的内容，设每日上限（默认 50，可调）。
- **按课复习**：在课程地图上点任意一课的"复习"，复习这一课的全部内容。结果同样计入间隔安排。
- **错题集中练**：最近答错的内容。

## 5. 音频

### 5.1 来源与优先级

每个句子和词都有一个固定的 `audio_id`。播放时按以下顺序找到第一个存在的音频：

1. **真人录音**（你儿子录的，录音模式产生）
2. **NN 原版切片**（资料包提供）
3. **Azure 合成音**（预先生成好、随程序或资料包分发）
4. 都没有：按钮显示为灰色

### 5.2 合成音

- 声音：nl-NL-FennaNeural（女声）为默认，对话中的男声角色用 nl-NL-MaartenNeural。
- **只在构建时生成，运行时不合成。** 我们自己写的内容（仓库里）由 GitHub Actions 生成；资料包里需要合成的词和句，由 DS 在你电脑上生成。
- Azure 免费层（F0）限制每 60 秒 20 次请求，脚本按每 3.2 秒 1 次的节奏，并按"文字 + 声音"做缓存，只生成一次。

### 5.3 播放与录音

- 正常速度和 0.75 倍慢放（变速不变调）。
- 录音跟读：录下自己的声音，可以"原声 / 我的 / 交替"播放，并排显示两条声波。录音只保留每句最近 3 次。

### 5.4 发音评分（可选）

- 在设置里填入 Azure 密钥和区域后开启。已核实 Azure 发音评估支持 nl-NL。
- 荷兰语能得到准确度、流利度、完整度、总分，以及哪个词读得不好。没有韵律评分，也不显示音素名称。
- 评分会消耗 F0 每月 5 小时的语音识别额度，界面上显示本月已用量。

### 5.5 录音模式（给你儿子用）

- 在设置里进入。按课逐句列出所有句子和词，显示当前用的是哪种音源。
- 逐句录音 → 回放 → 满意就保存。保存后自动替换该句的播放音源。
- 支持"只看还没有真人录音的"、标记"这句不自然"（反馈给内容修订），以及导出 / 导入录音文件夹。

## 6. 词条

| 字段 | 例 | 说明 |
|---|---|---|
| lemma | wonen | 原形 |
| pos | ww. 动词 | 词性：荷兰语缩写 + 中文 |
| article / plural | het huis, -en | 名词才有 |
| verb_forms | ik woon · jij woont · hij woont · gewoond | 动词才有；A1 显示现在时，过去分词等到 G14 之后才显示 |
| separable | op·bellen | 可分动词 |
| zh / en | 居住 / to live | 我们整理后的释义 |
| zh_nn / en_nn | 住 / live | NN 官方词表的原始释义，保留供对照 |
| examples | 本课出现它的句子 | 自动关联 |
| audio_id | — | 词的读音 |

- 句子里的每个词都能点开，显示的是对应的词条（`woont` → `wonen`）。
- 词性缩写：zn. 名词 · ww. 动词 · bn. 形容词 · bw. 副词 · vnw. 代词 · lidw. 冠词 · vz. 介词 · vw. 连词 · telw. 数词 · tw. 感叹词。

## 7. 界面

- **风格**：A + C，清爽现代为主，局部用沉浸式深色。效果图见 claude.ai 上的"Dutch Tutor UI 风格对比"画布，下排为采用方案。
  - 浅色底 + 白卡片；主色深蓝 `#1E3A8A`，强调色荷兰橙 `#FF7A1A`。
  - 播放条、"继续学习"卡片这类重点区域用深色发光设计。
  - 字体：Plus Jakarta Sans（拉丁文）+ Noto Sans SC（中文），**打包进程序**，离线也能正常显示。
- **主题**：浅色 / 深色 / 跟随系统。深色主题保持同一套设计语言，只换配色。
- **字号**：荷兰语句子随窗口大小自适应；设置里另有荷兰语、中文、英文三个独立的缩放滑块（80%–150%）。
- **英文开关**：顶栏一键开关，全局生效，状态记住。
- **导航**：左侧栏放首页、课程、复习、发音练习、模拟考试、设置。窗口变窄时收起为图标，为以后的手机版做准备。
- **页面**：
  - 首页：继续学习、今日复习数、学习天数、课程地图入口。
  - 课程地图：A1 / A2 / B1 / B2 标签页（后三个灰色）；分区显示发音入门、正课、测验；卡片显示状态和进度。
  - 上课页：按第 3 节的流程。
  - 复习页、发音练习页（自由跟读任意已学句子）、模拟考试页、设置页。
- **激励**：只做轻量的，包括学习天数、每课掌握度圆环、今日完成量。不做积分和排行榜。
- **内容报错**：每张句卡、词卡上有一个"报错"小按钮，记录到本地反馈文件，可以导出交给后续施工会话统一修订。

## 9. 技术架构

| 层 | 选择 | 说明 |
|---|---|---|
| 外壳 | **Tauri 2** | 独立窗口；Windows 用系统自带的 WebView2；以后可以出安卓版 |
| 界面 | React + TypeScript + Vite | CSS 变量做设计规范（两套主题） |
| 本地存储 | SQLite（Tauri SQL 插件） | 学习进度、复习安排、录音索引、反馈 |
| 课程内容 | JSON，随程序打包 | 仓库里我们自己写的内容 |
| 资料包 | 导入到 `%APPDATA%\nl.dutchtutor.app\nn-pack\` | 一次性复制，几秒钟完成；之后从本地读取 |
| 音频播放 | Tauri 资源协议 + HTML5 Audio | 慢放用 `playbackRate`（保持音调） |
| 录音 | WebView 的麦克风接口 | 存到 `%APPDATA%\nl.dutchtutor.app\recordings\` |
| Azure 评分 | REST 接口，从程序后端（Rust）发出 | 密钥存在本机，不进仓库，不进日志 |
| 测试 | Vitest（单元）+ 内容校验脚本 | 每次提交在 GitHub Actions 跑 |
| 打包 | GitHub Actions（windows 环境）→ NSIS 安装包 `.exe` | 每次合并到主分支自动出包，可在 GitHub 的 Releases 下载 |

- **没有后台服务器、没有登录。** 关掉窗口，程序就退出了。
- 安装包里**不含**资料包。第一次运行时提示"导入 Naar Nederland 资料包"，选中 DS 整理好的文件夹即可。不导入也能用发音入门和我们自己写的内容。

- 正课在运行时由"仓库里的编排" + "资料包里的句子、录音、练习、词条"合并而成。
- 资料包没导入时，正课显示为"需要资料包"。

## 11. 自动检查规则（内容校验脚本）

在 GitHub Actions 里跑仓库部分；DS 在本机加 `--pack` 参数跑完整检查。

1. 所有 id 唯一，所有引用（句子、词、音频、小贴士）都能找到。
2. 每个句子都有荷、中、英三项；每个词条都有词性和中、英释义；名词都有冠词。
3. 我们自己写的句子：音频 ≤ 5 秒（发音入门课 ≤ 4 秒）。NN 原版句子 > 5 秒的只做标记，不报错。
4. 句子里的每个词都能映射到词条（按 lemma 或已知词形）。
5. **生词规则**：一课里出现的词，必须是本课新词、此前课程的词，或者功能词白名单里的词。每课违规数显示在报告里。
6. 练习：每道选择题有且只有一个正确答案，干扰项和正确答案不重复。
7. 每课句子数和新词数在设定范围内，超出的提示拆分。
