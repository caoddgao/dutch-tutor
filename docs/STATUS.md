## T1 试用清单（用户）

1. 从 GitHub Releases 下载最新预发布 `Dutch.Tutor_0.1.x_x64-setup.exe`，安装（覆盖旧版即可）。
2. 设置 → "导入资料包" → 选 `F:\Working_Projects\Dutch_Tutor_v2\NN_Pack\nn-pack\`。看：几秒内显示"已导入 · 4 课"；
   课程地图出现第 21–23 课。
3. 学第 21 课：① 听原版（文字默认隐藏）→ ② 逐句学。看：**原版录音切分是否准确**、句卡和字号是否合适、点词出词条。
4. 在逐句学里点"跟读"录一句：Windows 第一次可能问麦克风，录完自动"原声 → 我的"播放，两条声波都出现。
   录不上时把提示原话发回来。
5. 做完 ③ 词卡和 ⑤ 练习（含课本练习、示范题、口头题），到 ⑥ 完成。看：题目是否顺手、数量是否合适。
6. 中途退出再进第 21 课：应回到退出时的那一步那一句；首页"继续学习"指向它。
7. 复习：第二天首页"今日复习"有数字（当天想试就点课程卡上的"复习"按课复习），三种方式 R1 / R2 / R3 都试一下。
8. 试 P01、P02：音 → 关键词 → 短句 → 听辨练习。P01 的关键词和练习会用到资料包第 5 课的原声。
9. 设置里试：深色主题、字号、英文开关、0.75×、每日复习上限、关掉某种复习方式。
10. 把觉得别扭的地方（截图 + 一句话）交给审核会话。
